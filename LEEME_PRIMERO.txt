FERREMAX · TIENDA + PANEL ADMINISTRATIVO

1. Descomprime toda la carpeta ferremax. No ejecutes dentro del ZIP.
2. Instala Node.js 22.12 o superior (Node 24 LTS también funciona).
3. VS Code > Archivo > Abrir carpeta > ferremax.
4. Terminal > Nueva terminal:
   npm.cmd ci        (Windows PowerShell)
   npm.cmd run dev
   En Mac usa npm ci y npm run dev.
5. Abre http://localhost:5173
   Panel: http://localhost:5173/login
   Registro de clientes: http://localhost:5173/registro
   Ingreso de clientes: http://localhost:5173/ingresar
